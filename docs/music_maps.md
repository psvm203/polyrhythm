# 음악 기반 캠페인 맵

1스테이지는 기존 Freaky WAV의 첫 55초를 그대로 재생한다. 2~8스테이지는 원본 곡에서 드럼이 선명한 구간을 `level/data/music/stage_N.ogg`로 추출했다. 게임 실행에는 `.songs`가 필요하지 않다.

게임에서 직접 사용하는 1스테이지 원본 WAV만 `level/data`에 보관한다. 2~8스테이지는 `level/data/music`의 Ogg를 재생하며, 사용하지 않는 원본 WAV와 해당 `.import`는 삭제했다.

| 6 | Music Is Life | 140.000 | 54.86 | 125 |

## 스테이지 9: Matadora

`level/data/music/matadora.mp3` 전체를 재인코딩 없이 재생한다. `python3 scripts/generate_matadora_map.py`로 이 스테이지만 재생성할 수 있다. 기존 1~8 생성기는 9의 분석 기록을 보존한다.

80~180 BPM 후보를 음원의 스펙트럼 변화와 비교해 130 BPM을 찾고, 주변 템포를 정밀 분석해 위상 0.027초를 얻었다. 4/4 기준 48마디를 직접 구성한 뒤 각 입력을 원본 MP3에서 검출된 35ms 이내의 타격음에 맞췄다. 특히 마디 내 1.5·2.5박의 강한 엇박을 중심으로 정박, 짧은 반 박자 연타, 응답 패턴과 쉼을 배치했다. 최소 입력 간격은 약 215ms다. 삼각형은 짧은 응답, 오각형은 엇박, 육각형·팔각형은 구간 시작이나 긴 간격을 나타낸다.

| 구간(초) | 전개 | 입력 수 |
|---|---|---:|
| 0~14.80 | 도입: 여유 있는 엇박에서 짧은 연결로 확장 | 27 |
| 14.80~29.57 | 첫 강세: 연타와 쉼을 교대 | 38 |
| 29.57~42.49 | 정박과 엇박의 주고받기 | 32 |
| 42.49~44.33 | 한 마디 전환: 반 박자 뒤에서 시작 | 4 |
| 44.33~59.10 | 두 번째 강세: 첫 구간과 다른 마디 조합 | 39 |
| 59.10~66.49 | 브레이크: 입력 밀도를 낮추고 긴 쉼 확보 | 10 |
| 66.49~72.03 | 재상승: 짧은 연결과 마지막 진입 준비 | 11 |
| 72.03~88.62 | 피날레: 강한 엇박과 연타 후 마무리 | 44 |

`repeat_count: 1`로 전체 진행을 저장하며 음악을 중단하는 이벤트는 없다. 스테이지 8 클리어 시 해금되고, 선택 화면은 5열 2행으로 9개 카드를 표시한다.

## 생성과 판정

`python3 scripts/generate_music_maps.py --source-dir /path/to/originals`로 재생성한다. 재생성하려면 삭제한 2~8스테이지 원본 WAV를 별도로 다시 확보해 해당 폴더에 제공해야 한다. 원본이 없으면 기존 음원·맵을 변경하기 전에 중단한다. Python + NumPy와 Vorbis 인코더를 제공하는 FFmpeg가 필요하다. 원본 곡명·SHA-256·추출 시작 시각·분석 BPM·각 타격음 위치는 `docs/music_maps.json`에 기록한다.

22,050 Hz, 128샘플 간격(약 5.8ms)의 스펙트럼 변화로 타격음을 추출하고, 파일명 BPM 주변에서 실제 음원에 가장 잘 맞는 템포와 위상을 찾는다. 박자 근처 35ms 이내에 검출된 타격음만 사용한다. 1스테이지는 두 박자 간격, 2~6은 기본 박자를 사용한다. 7~8스테이지는 빠른 곡을 편하게 칠 수 있도록 두 박자마다 입력하는 하프타임 맵으로 구성하고 빠른 엇박 연타를 제거했다. 최종 Ogg를 다시 디코딩해 타격음 위치를 보정하며, 원본 타격음과 20ms 이상 차이 나는 불확실한 후보는 제외한다. 무작위 도형 배열이나 누적 BPM 계산으로 입력 시각을 만들지 않는다.

`note_times_sec`는 음악 재생 시작을 0초로 한 절대 입력 시각이다. 이벤트로 도형이 분할된 **후**의 도형마다 하나씩 존재한다. `NoteTimeline`이 같은 시각을 도형 접촉과 판정에 사용하므로 변 수가 달라도 오차가 누적되지 않는다. 도형 크기는 다음 입력까지의 박자 간격과 반복 박자 위치에서 결정한다. 네 박자 주기의 시작은 육각형, 중간은 사각형으로 구분한다. 2·3스테이지에는 보스나 특수 이벤트가 없다. 3스테이지의 연속 삼각형은 일반 도형으로 저장해 기존 입력 시각을 유지한다. 시간 정지는 기존처럼 음악과 게임 시계를 함께 멈춘다.

명시적 입력 시각이 없는 기존 사용자 맵은 이전 BPM 계산식을 계속 사용한다. 편집기로 가져온 음악 맵의 시각과 종료 길이는 저장 시 보존한다. 도형 추가·삭제 또는 분할 이벤트 변경 후 시각 수가 맞지 않으면 검증에서 오류로 알린다.

## 검증 범위

`tests/campaign_music_test.gd`는 9개 스테이지의 실제 씬을 실행해 모든 입력 시각에서 도형 접촉과 Perfect 판정, 보스 클리어 가능성, 음악 길이와 종료, 전체 해금 저장 및 기존 기록 보존, 9개 카드와 해금 버튼의 화면 배치 및 마지막 카드의 키보드 이동을 검증한다. `tests/timing_level_regression_test.gd`는 Matadora의 마디 패턴 다양성, 입력 간격, 브레이크 밀도와 시작·종료 여유도 검증한다. 장치의 실제 오디오 출력·입력 지연은 기존 설정의 입력 오프셋/보정 기능으로 조절한다. 음원 분석과 자동 테스트는 실제 스피커·헤드폰에서의 청감 검증을 대체하지 않는다.
